# Laura & Alex Wedding Trip — Production PWA

Final merged Progressive Web App for the November 5–8, 2026 Manassas wedding trip.

## Production features
- Warm wedding-focused mobile design
- Day-by-day itinerary and Today card
- United flight details and seats
- Two Tempo by Hilton reservations
- Full wedding-day shuttle / ceremony / reception / afterparty schedule
- One-tap maps and phone links
- Calendar (.ics) import
- Expanded persistent packing / readiness checklist
- Installable and offline-ready PWA
